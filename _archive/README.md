# Archived ZAKTec Solutions template

This directory preserves the original Astro AI SaaS template as it existed at Git checkpoint `658e10c` before the consultancy redesign.

## Contents

- `pages/` — all original routed pages, including the SaaS demo, dashboard, component showcase, blog, pricing-related content, and legal pages.
- `components/` — all original React and UI components, including pricing, testimonials, metrics, chat, and showcase components.
- `layouts/` — the original shared page layout.
- `styles/` — the original global stylesheet.
- `assets/` — the original public assets and template screenshot.
- `config/` — the original Astro, Tailwind, PostCSS, package, TypeScript, brand, and deployment configuration files.
- `docs/` — the original README and TODO documents.
- `content/` — reserved for archived content collections; no `src/content/` directory existed at the checkpoint.

Archived files are retained only for reference and reuse. Nothing in this directory is imported by the active website, and Astro does not generate routes from it.
